# Axiom-Wallet

Axiom Wallet is a high-performance, institutional-grade Solana wallet, DEX aggregator, perpetual trading terminal, and live copy-trading platform.

## Features
- **Wallet & Portfolio**: Multi-asset management, real-time balance tracking, and secure deposit/transfer flows.
- **DEX & Perp Trading Terminal**: Live candlestick charts, high-density order book, instant execution, and pair watchlists.
- **Live Leaderboard**: Real-time rankings of top traders, live execution feed, win-rate tracking, and 1-click copy trading.
- **Admin & Agent Portals**: Real-time user management, fee distribution, referral slugs, and deposit management.
- **Dark & Light Mode**: Complete theme customization with high-contrast glassmorphic design.

## Tech Stack
- **Frontend**: React, TypeScript, Vite, Vanilla CSS design tokens.
- **Backend**: Python, Django REST Framework, SQLite / PostgreSQL.

## Getting Started

### Client
```bash
cd client
npm install
npm run dev
```

### Server
```bash
cd server
pip install -r requirements.txt
python manage.py runserver
```
